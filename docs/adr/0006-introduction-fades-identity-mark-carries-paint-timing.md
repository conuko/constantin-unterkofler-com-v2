# Let the introduction fade; the Site Header identity mark carries paint timing

ADR-0004 kept every Portfolio Page's introduction opaque at first paint so that Chrome would record First and Largest Contentful Paint at all, which made it the one above-the-fold element that only settled instead of fading. That read as the paragraph being already there before the page arrived, so the introduction now fades in from transparent like every other record part, a beat slower. The standing constraint is unchanged — at least one paint-eligible, above-the-fold element must be opaque in the server-rendered HTML — and the Site Header's identity mark now fills it on every page by having no entrance at all: it is static, opaque from the first frame. Measured on the production build: with the introduction fading and nothing else opaque, no FCP and no LCP are reported; with the mark opaque, both are recorded at first paint. The mark is the notebook's stationery, printed before the entry is written, which is why it alone does not animate. Starting the introduction at a near-zero opacity would also satisfy Chrome, but only by gaming the measurement, and was rejected.
