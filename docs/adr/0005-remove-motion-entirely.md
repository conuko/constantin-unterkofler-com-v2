# Remove Motion and drive Site Header interaction with CSS

ADR-0004 moved the entrance choreography to CSS and kept three interactions on Motion — the mobile wayfinding disclosure, its control's three lines, and the active-route underline's shared layout animation — on the grounds that they run after load and cost nothing on the critical path. Measuring the production build showed otherwise: the Motion chunk still shipped to every page (172KB parsed, 53KB transferred, 69% of it unused) for those three interactions alone, and the remaining LCP gap was render delay from JavaScript, not from the choreography. Motion is therefore removed entirely. Every animation is CSS — `app/motion.css` or a Tailwind utility — the reduced-motion preference comes from `matchMedia` through `lib/use-prefers-reduced-motion.ts`, and the root layout wraps only the theme provider, so no animation library is downloaded, parsed, or hydrated on any Portfolio Page.

## Consequences

- **The disclosure stays in the DOM.** Its panel transitions between closed and open on `visibility`, `opacity`, `translate`, and `scale`, so the exit reuses the entrance rules with nothing watching for unmount, and its items ride the same DOM-order stagger the record groups use. `visibility` runs on a `linear` curve because a discrete property maps the spring's overshoot onto its end value, which would blink the panel hidden midway through its exit.
- **The underline no longer slides; it draws.** Motion's `layoutId` animated one element's box across to another's, which CSS cannot express. The current route is now marked by the link's own rule drawing open through the `underline-reveal` utility while the previous one retracts — the move every other rule in the notebook makes. The same utility reveals a rule on hover, which the wayfinding links did not do under Motion.
- **View Transitions were considered and set aside.** React's `<ViewTransition>` would restore a genuine morph, but in Next.js 16.2 it sits behind `experimental.viewTransition` and crossfades the whole document on every navigation, which would fight the entrance choreography ADR-0004 established. Reopen this only if the slide is judged worth that trade.
